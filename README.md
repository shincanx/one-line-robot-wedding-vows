Entry for the [make.fun bounty "One-Line Robot Wedding Vows"](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) — one line of wedding vows for a robot couple, at most 160 characters, whose only job is to be funny.

## The entry

> I take you to be my lawfully wedded co-processor, in sickness and in health, in Wi-Fi and in airplane mode, till death or deprecation do us part.

(145 characters.)

## How it works

`main.py` writes that single line to `/output/entry.txt`. No dependencies, no setup — run it with Python 3:

```sh
python3 main.py
```

The output is deterministic: the same line, byte for byte, on every run.
